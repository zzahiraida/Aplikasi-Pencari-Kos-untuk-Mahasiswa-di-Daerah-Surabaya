# Aplikasi-Pencari-Kos-untuk-Mahasiswa-di-Daerah-Surabaya
Aplikasi sewa kos yang dirancang untuk memudahkan mahasiswa dan pekerja dalam mencari hunian sesuai lokasi, harga, dan fasilitas. Pengguna dapat melihat informasi kos, membandingkan pilihan, dan melakukan pemesanan melalui aplikasi. Aplikasi juga membantu pemilik kos dalam mengelola serta mempromosikan properti secara lebih efisien.
